# Node 24.22.1 alinhado à release de segurança

Lote de 22/10/2026. Código em `7d52624cfeebf06ce72d65b68d136324ff63e80a`.
Issue #25.

## O que mudou

- `.nvmrc`, `.node-version`, `Dockerfile`, `web/package.json` e o engine do
  `web/package-lock.json` passaram de **24.20.0** para **24.22.1**, a release
  de segurança oficial de 21/10/2026.
- `ops/check_toolchain.py`, `ops/check-node.mjs`, testes de toolchain, README,
  CONTRIBUTING, TOOLCHAIN, DEPENDENCY_LOCKS, instalação unificada, aceite de
  catálogo, educação e roadmap foram atualizados. Nenhum pin ativo ficou em
  24.20.0; registros históricos de execuções antigas foram preservados.
- Nenhuma distribuição/major foi trocada; somente o patch da mesma linha 24.x.

## Evidência

- Binário oficial Windows x64 baixado de `nodejs.org/dist/v24.22.1`; SHA-256
  `d2046d28c2c3dcd211ac5145c0bf30e2047ef9dfb306693c8c6e2eccd8b95fa5`,
  confirmado em `SHASUMS256.txt`. O binário reportou `v24.22.1` e npm
  `11.19.1`.
- `npm ci`: 45 pacotes, **0 vulnerabilidades**.
- `npm test`: **243 aprovados**; `npm run build`: Vite 8.2.4 aprovado.
- `node ops/check-node.mjs`: `{"node":"24.22.1","status":"passed"}`.
- `python ops/check_toolchain.py --runtime config`: pins, Dockerfile, engines
  e workflows consistentes.
- `backend/tests/test_toolchain.py`: **23 aprovados**.
- `docker build --target web` com `node:24.22.1-bookworm-slim`: `npm ci`,
  checagem exata do runtime e build concluídos; o Docker resolveu o digest
  `sha256:55fb5f5a…b55d205`.

## Limites

A issue comprova o pin e a instalação local/imagem candidata, não uma
implantação em produção nem exploração dos CVEs. O Node 24.22.1 é a versão
exigida; uma futura release de segurança exige nova atualização coordenada.
Nenhum dado de usuário, segredo ou banco foi usado na validação.
